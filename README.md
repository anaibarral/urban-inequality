# Urban Inequality Analysis

This repository contains the code used to build and analyze measures of spatial inequality across global urban centers.  
The workflow integrates open geospatial and political datasets —including nighttime light imagery, gridded population data, and regime classifications— to estimate within-city inequality indicators such as luminosity gradients and Gini coefficients.

## Structure
- `scripts/` — R and Python scripts for data processing and analysis.  
- `figures/` — Visualization outputs (e.g., gradient plots, maps, and regression figures).  
- `tables/` — Regression tables and descriptive summaries in `.tex` format.  
- `docs/` — Supporting documentation and draft text for the manuscript.

## Reproducibility
All scripts are designed to be reproducible. Each file specifies the data source URLs and processing steps needed to recreate the outputs used in the analysis.  
Due to data size constraints, input datasets are not included in this repository.
